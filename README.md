# MHX Studio

Windows x64原生GUI，面向雷电单台游戏启动与指定角色登录测试。后续版本只通过软件内“一键检查更新”升级，自动校验、备份、保留配置/页面标定、健康检查及失败恢复。

用户真实验收基线preview.17：软件内升级、雷电24实例发现、单台启动、全关闭后五台批量启动、ADB。V3.3游戏内返回登录并重新进入角色路径为人工ADB已测；新游戏全自动功能待实机验收。
