# 长期开发及交付规则

依据用户2026-10-27指令。适用于全部后续开发版本；不能因新增功能取消。

1. 所有后续升级通过软件内“一键检查更新”；除首次安装、紧急恢复或用户明确同意外，不要求手动下载ZIP、解压或替换EXE。
2. 每次发布提供可匿名访问的清单、下载地址、版本及SHA-256；实际下载复核文件字节与Windows x64 PE。
3. 保留用户配置、雷电路径、分组、职业与角色设置、游戏绑定及页面标定。保留未知配置字段；更新不提交未保存的界面草稿。
4. 更新前备份EXE及配置。下载/校验失败不替换；备份/替换/启动健康检查失败安全停止或恢复旧版与配置。保留唯一备份，不覆盖旧发行资产。
5. 长期保留Windows原生失败回滚测试：启动超时、立即退出、失败版本改写配置后的恢复、SHA篡改、文件占用。真实机器故障回滚尚未验收，不能标记实机通过。
6. 每次发布回归雷电自动发现、单台启动、全部关闭后的五台批量启动、动态分组和ADB身份验证；CI替身结果不等同真实雷电成功。
7. Windows自动测试、代码完成、用户真实雷电/游戏实机验收分别记录。未知页面、身份变化、识别冲突或超过重试次数时停止危险操作并保存有限诊断。
