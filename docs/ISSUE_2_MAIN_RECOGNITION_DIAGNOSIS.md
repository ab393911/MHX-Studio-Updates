## 已核对的实现

- 本地 `profiles/1.json` 优先于内置 game 模板，原实现每次检查重新读取文件；没有证据证明实机使用了旧模板缓存。
- ADB 截图每次先验证实例身份，再调用 `adb -s <serial> exec-out screencap -p`；正常截图缓存没有读取入口。
- 解码要求原始960×540；框选窗口按原尺寸在客户区 `(20,70)` 显示，鼠标坐标减去该偏移；没有截图缩放逻辑。
- 每框固定32×16采样，512个8位灰度值。平均绝对误差必须≤threshold；灰度差>40的采样点必须≤40。两个特征都必须通过。threshold=10不是相似度百分比。
- 原来 game 页面重复登记两个中文名称，所以同一次成功日志会显示两次名称；并非两个独立算法均通过。移除重复登记，不改持久化页面键。
