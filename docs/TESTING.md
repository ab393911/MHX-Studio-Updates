# 当前仅验收在线更新

1. 保持当前preview.15运行，点击“一键检查并更新”。旧EXE有原确认框，首次点一次“是”；以后新版本只点“一键检查更新”。
2. 不打开浏览器、不下载ZIP、不解压、不运行任何命令，等待软件自动完成下载、SHA-256校验、备份、替换和重启。
3. 重启后，窗口顶部版本应高于preview.15，更新状态显示“更新成功：当前版本…”。原重试次数、分组、职业绑定、标定和其他已保存设置应保留。
4. 核对雷电路径、24台实例、已运行数量和ADB状态。选择原先可启动的一台未运行实例，检查启动及ADB验证仍正常。无需关闭原模拟器。
5. 再点新版本“一键检查更新”，若无更新，应显示“当前已是最新版本”。
6. 若失败，按界面结果反馈；不要删除程序目录.mhx-backups/.mhx-updates或数据目录.mhx-rollback。自动回滚的故障注入由开发端Windows环境测试，不要求用户修改EXE或故意破坏文件。

首次兼容限制：preview.15的确认框和更新器逻辑已经编译进旧EXE，不能通过清单取消。旧15第一次升级的配置快照在新程序健康确认前补建；本版以后的升级在替换前备份EXE和配置。不能把首次从15升级称为“零确认”。

Windows自动测试覆盖原生EXE替换、失败回滚、配置被失败版本改写后的还原、快照校验、保留未知字段；另实际运行已发布preview.15验证在线升级。零确认测试用当前源码构建的旧版本号基线，报告baseline_published=false。升级后24实例检测及启动使用接口模拟，仍需要用户真实电脑验收。

已保存配置才是更新保留对象；未保存的界面草稿不会因点击更新被自动提交。更新过程中已有操作会先安全取消，模拟器窗口保留。

本轮不验收游戏登录、切换角色或任何游戏任务。Windows真实电脑完成一键升级前不开发新游戏功能。
