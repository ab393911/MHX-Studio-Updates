# 图标标定与多锚点草稿（未发布）

仅为识别验证与后续入口复用准备，不接入现有登录、角色切换或游戏点击。现有页面规则继续按原路径加载。草稿库缺失/损坏不会影响旧登录；草稿诊断自身遇到错误即停止。

## 界面

页面规则管理 → 图标草稿（仅诊断）。选择本实例或五开共享范围，再选择玩法、交易/交易行、队伍、背包、菜单、境界、常用候选；ID和中文名称可修改，名称不表示功能已验证。

实时截图并框选：按顺序选2～8个不同、不重叠的6～24像素高对比图标核心，避开红点/数字/背景；最后单独框实际按钮范围，必须包含这些特征。点击保存才持久化，取消不写文件。原图仍960×540、不缩放。特征质量检查只排除低信息区域，不证明跨场景可靠。

保存后在相同取图上重读评分；这只是保存完整性自检。重开窗口/重启软件从磁盘读取，下一次诊断使用新截图。多人/多机共享前必须逐实例验证布局。相同960×540不是布局一致的充分条件。

至少保存3个互不重叠按钮范围的图标后，点击“组合主界面候选”仅修改JSON预览，还需显式保存确认。恢复历史/导入JSON同样先预览再确认保存；冲突SHA拒绝覆盖，旧文件先保留。没有自动上传、规则下载或自动改已验证标定。

## 格式及存储

复用automation.Profile的pages、anchors、buttons、PageScore。IconRules外层schema=1，width=960，height=540，revision递增；main_icons列出独立图标ID；min_icons至少2；stable_frames为2或3。blockers可引用同Profile内的已标定遮挡页，命中任一帧就拒绝主界面候选。每图标的全部特征须通过原均值10、超差点40的双重门槛，逐特征阈值也固定10。低信息模板被拒绝，未降低匹配门槛。

本机共享profiles/icon-drafts/shared.json；本实例profiles/icon-drafts/<编号>.json覆盖同ID规则。草稿history保存于同目录下；不覆盖profiles/shared.json或profiles/<编号>.json。存储位置复用更新器现有profiles递归备份/恢复，相关自动回归验证，无SQLite迁移。任务状态、截图缓存、错误记录和设备身份不在共享规则中。

两帧诊断调用原Screenshot身份核验，取图后再次Verify，并复用gameUI取消/实例保护，最多采样3次、间隔250ms，不改1.2秒UI定时器或12秒设备扫描。必须同一设备身份且不同采样序号；同样至少2个图标在全部帧通过，不能用第1帧A+B、第2帧B+C凑数。无候选、规则损坏、尺寸不符、已知遮挡或证据不足均报告停止。ActionAllowed恒false，即使candidate_main=true也不允许任务操作。

报告在原诊断窗口查看/复制/看原图/导出ZIP，含每图标每帧逐特征误差与阈值、规则版本/有效SHA、取图身份与像素SHA。报告和最后一帧只保存在当前实例独立诊断目录，含用户画面，分享前需脱敏。前台覆盖页面可能保留足够UI，未配置的遮挡不能保证发现，所以当前仅草稿。

## 当前真实样本与缺口

单张获准脱敏PNG上，背包/菜单/境界各两处小核心可以精确匹配，6处标准差34.976～56.956。它证明模板可提取及持久化回放，不是跨视角稳定性；不会给用户自动装入测试ROI。玩法与交易的静态提取在私有原图测试，公开PNG对应上方区域被遮盖，不能拿遮盖黑块当图标。队伍入口的实际含义未确认；常用仅列候选。

已有真实原规则误差73.24609375 / 64.423828125，阈值10，仍明确失败。旧框36×46、31×44包含部分变化场景，算法按固定框512灰度采样等权比较，确实可能受背景影响；原ZIP诊断的边缘误差为127.233/111.028，内部为44.967/40.012；当前均值亮度较模板增加73.246/64.307，±2像素搜索最优偏移仍0/0，故不是简单微小坐标平移能解决。但还缺成功/失败成对帧，不能认定唯一根因。没有自动改原规则，没有要求用户当前重标定。

自动回归包括真实静态PNG、模拟背景变化/图标缺失/红点范围外变化、常量屏、遮挡、交替证据、跨实例、重复采样、原子写失败、共享与实例覆盖、持久化/历史恢复及原更新快照回滚。合成变化不当成真实人物移动、视角旋转或实际红点动画验收。

受控验收仍需：同版本不同视角/移动/场景/红点与图标状态的原始图，公告、角色页、菜单/交易等真实负例及弹窗；先只读诊断，观察误识别，再决定是否授权规则接入执行器。未知页面停止点击和现有有限重试规则保持。
