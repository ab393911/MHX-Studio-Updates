# 用户电脑测试步骤

此版本为开发实测版。中文OCR货币截图检查独立运行，尚不能作为已通过能力宣传；货币读数必须与用户电脑上的游戏画面对照。新游戏功能尚未通过真实游戏验收；软件中的“核验结束”只表示本次运行通过了程序设定的画面检查，仍需用户对照游戏确认。

## 安装

在当前preview.21内点击一次“一键检查更新”。等待下载、校验、备份和自动重启，核对新版本号、原雷电目录及职业/游戏绑定。无需手动下载、解压、替换EXE或执行命令。失败时查看明确结果，不手动删除旧备份。

## 先测试组队与八星

1. 主窗口打开“五开工作台”，勾选要测试的五台，确认职业为1合欢、1天音、1青云、2鬼王。先在游戏内把固定队预设设为这五个账号的本槽角色。
2. 如果当前没有五开计划，填写当前区服并点“建立五开计划”。原失败/待核查任务不会自动记为完成。
3. 打开“五台同槽登录准备…”，确认目标区服、共同角色槽位、队长实例。当前已有区服特征为“一梦诛仙”，其它区服没有对应画面依据时停止。
4. 勾选“登录后执行所选任务（测试）”，项目选“组队→八星→资产→后续计划”，点“预检并登录所选五台”。首次测试先观察，不开启无人值守。
5. 对照游戏检查：目标槽位及职业、实际五人组队、8★打符/覆盖/强化选项、职业幻形对应目标及8★、完成后“冻结”、是否回主界面。缺卡购买最多一次；结果不明不重买。
6. 尚未接通据点战斗时程序会停住，保留任务未完成，不会自动换槽、换服绕过它。随时可点“停止”。

已有五人固定队预设是前提；未核验页面不会盲点。不需要昵称OCR或昵称标定。单项测试只手动运行；不能把单项保存成完整流程的自动启动方案。

## 独立测试资产、聚福、战令及据点识别

同一窗口的项目下拉框可选：

- “只读取当前五角色银锭/功绩”：进入普通好友的礼物查询页读取余额并返回。不会赠送、加买家或发消息。对照原显示数字和工作台当前区服汇总。每角色可用量为min(整万银锭数,整百功绩数)×1万；零头不跨角色合并。未扫描、失败、过期分别显示，不能当作余额零。
- “只测聚福激活”：只处理妖灵据点、魔宗妖王，已激活不重复；读取实际成本、核验扣费。福气不足时的绑玉补充未完成，不会猜周剩余额度兑换。
- “只测仙盟战令/打工簿”：只做战令的消耗活力任务和明确可领奖励，不恢复已删除的日课。
- “只识别本周赛季据点”：读取首领后返回，不发起挑战，不记通关。

四区汇总展示已配置区服和已发现模拟器的记录；必须实际扫描过相应角色才能计入金额。目前未实现自动遍历四区全部角色，不把已扫描的小部分当作全机已完成总额。

## 出错时

点停止，保留程序显示的错误、实例编号、槽位和停留页面。通过主窗口“查看异常截图”检查程序保存的诊断。正常截图保持有限内存缓存；不需要用户打开命令行。重复测试涉及消耗时先确认上一次实际结果。

明确未完成：据点实战、交易行完整下架/重上架、福气不足自动兑换、全角色/区服/批次无人值守轮转。真实机器故障回滚仍未验收。
