MHX Studio 更新与登录测试版

1. 解压到新文件夹，保留原 V3.3/V3.4，双击 MHXStudio.exe。
2. 先点“一键检查并更新”。无需安装 Python，无需执行命令。
3. 有更高版本时，会先提示确认，再下载、核对 SHA-256、备份和替换。
4. 新版本启动失败会回滚；每次旧版备份独立保留，不自动删除。
5. 程序打开后会自动查找雷电，并在空闲时每12秒刷新实例列表。
   支持旧版7列与雷电9/14的10列列表；从运行进程、Windows安装记录和常用目录查找。
   如果未找到，只需点“选择雷电程序”，选安装目录内 ldconsole.exe 或 dnconsole.exe。
6. 在“当前实例”选一台，点“启动当前模拟器”；或填写“五开首编号”，点“启动本组5台”。
   例如首编号6只操作6～10。已运行的实例不会重复启动，编号缺失则整组不启动。
   程序会等待并检查安卓启动状态；ADB未就绪的实例也会显示，不会当作没检测到。
   停止或超时会保留已打开的窗口；不会创建、删除、重置或关闭模拟器。
7. 游戏登录流程需要在你的电脑上标定与验收，先单台五角色闭环，再五开。
   具体步骤可在程序里点“查看验收说明”，或阅读 TESTING.md。

已验证与待验证：
- Windows 构建、原生窗口、EXE 替换与失败回滚：由 GitHub Windows 自动测试验证。
- 自动检测、自定义路径、7/10列列表、单台/本组启动按钮、异常隔离：有测试替身的Windows自动测试，不代表真实雷电已验收。
- 下载链接、更新清单、SHA-256：由发布流程匿名下载核对。
- 游戏页面识别、角色身份、雷电五开：实现了测试入口和状态核验，但尚未经过你的 Windows + 雷电 + 游戏实机验收。
- 职业目前人工绑定；不执行战斗、银锭交付或自动换区。

只有当前区服所有实例、每台五个角色的全部任务真正完成，才允许将来解锁换区。
登录测试不算任务完成，失败或跳过也不算完成。

首次使用本版采用独立数据目录，旧版配置保留原位；本版之后的在线更新保留本版配置。
GitHub 在你电脑的网络中能否直接访问，需要点击更新实测；没有宣称已部署国内镜像。
